One line from a hardware wallet that will not sign a transaction at 3 AM: the last 3 AM signature bought a dog coin, so the wallet is off the clock until sunrise — even its buttons need sleep.

> The last time I signed at 3 AM you bought a dog coin. I'm off until sunrise. Even my buttons need sleep.

## How it works

`main.py` (Python 3 standard library only) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
